# HarnessScope v0.2 workspace compatibility fixture

`workspace.sqlite` is a synthetic fixture for the released HarnessScope v0.2 SQLite contract.

It is generated by `scripts/make-v02-workspace-fixture.mjs` through the Node `src/core/store.mjs` schema/redaction path. The fixture contains only fixed synthetic IDs, timestamps, event data, and finding provenance. The generator intentionally supplies a sentinel secret through an `Authorization` field so tests can prove redaction occurs before persistence; the sentinel must never appear in the committed SQLite bytes.

Regenerate from the repository root with Node.js 22:

```bash
node scripts/make-v02-workspace-fixture.mjs
```
